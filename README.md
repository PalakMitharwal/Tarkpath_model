# Tarkpath demo (frontend only)

Open `index.html` in a browser, or run `python -m http.server 8000` and visit http://localhost:8000.

```
index.html      app shell
css/style.css   premium blue crystal theme
js/app.js       routes, sample data, demo logic
assets/logo.png Tarkpath emblem
```
Sample data only. No backend. Progress is saved in your browser (localStorage).
